# memo

開いてすぐ書ける、URL がそのままアドレスになるメモ帳。

## 使い方

1. `index.html` を開く
2. そのまま書く

それだけ。保存ボタンも設定もない。

## 動き

- **自動保存** — 入力した瞬間に保存される
- **URL がメモのアドレス** — 開くと `?id=<uuid>` が URL に付き、それが個々のメモの住所になる。同じ URL を開けば続きが書ける
- **消えない** — localStorage に保存するので、タブを閉じても残る
- **素で開くと新しいメモ** — `id` を付けずに開くたびに新しいメモが発行される。新しいタブで開けば別のメモとして使える点は変わらない
- **一覧ページ** — `list.html` で保存済みの全メモを最終保存日時とプレビュー付きで一覧できる。クリックでそのメモを開ける
- **自動削除** — 最終更新から 30 日経ったメモは自動的に消える。本文を空にしたメモもその場で一覧から消える
- **ダークモード対応** — OS の設定に追従

## 向いている用途

- ちょっとした下書き
- コピペの一時置き場
- 通話中のメモ
- 思考の整理
- 数日〜数週間残しておきたいメモ

## 向いていない用途

- 長期保存したい文書（30 日で自動的に消えます）
- 複数デバイス間での同期（同期しません。ブラウザ・端末ごとに別々のデータです）
