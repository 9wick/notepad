# memo

開いてすぐ書ける、タブごとに独立したメモ帳。

## 使い方

1. ページを開く
2. そのまま書く

それだけ。保存ボタンも設定もない。

## 動き

- **自動保存** — 入力した瞬間に保存される
- **reload しても消えない** — 同じタブならリロードしても内容が残る
- **タブごとに別のメモ** — 新しいタブで開けば別のメモ帳として使える。複数の下書きを並行して書ける
- **タブを閉じると消える** — 永続保存はしない。一時的なメモ用
- **ダークモード対応** — OS の設定に追従

## 向いている用途

- ちょっとした下書き
- コピペの一時置き場
- 通話中のメモ
- 思考の整理

## 向いていない用途

- 長期保存したい文書（タブを閉じると消えます）
- 複数デバイス間での同期（同期しません）
